# Ranger Desktop Alkalmazás

Ez az alkalmazás a Ranger projekt asztali fejlesztõi és teszetlõi alkalmazása.

## Telepítés
A telepítéshez töltse le a gyökér mappában található 'Ranger_desktop_install.zip' filet.
- csomgalja ki a .zip fájlt
- futtassa az 'install.exe' fájlt a telepítés megkezdéséhez
- kövesse a telepítõ utasításait a telepítés befejezéséhez
